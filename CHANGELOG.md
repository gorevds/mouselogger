# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [0.2.0] — 2026-06-06

Полная пересборка проекта в пакет `mouselogger` с акцентом на качество данных
для исследования аутентификации по динамике мыши.

### Исправлено (критичное)
- Кнопки опрашиваются через `GetAsyncKeyState` вместо `GetKeyState`, который без
  насоса сообщений мог вообще не фиксировать клики.
- `POINT` использует знаковый `LONG` — корректные координаты на мультимониторе.
- Автозапуск берёт путь к exe из `sys.executable`, а не из рабочего каталога.
- Низкоуровневый хук корректно ставится на 64-битной Windows (`restype/argtypes`).

### Добавлено
- Новая архитектура: `InputSource` → `Recorder` → `Sink` с узкими интерфейсами.
- Два бэкенда захвата: поллинг и событийный `WH_MOUSE_LL` (со скроллом).
- Формат логов JSONL со схемой версии 2 и метаданными сессии (экран, DPI, ОС,
  частота, согласие); посуточная ротация в рантайме.
- Сохранение пауз: событие `IDLE` с длительностью простоя.
- CLI `start/install/uninstall/status/purge`, гейт согласия, псевдонимный
  `participant_id` вместо логина (PII).
- Автозапуск через реестр Windows вместо `.bat`.
- Экспортёр признаков `mouselogger.export` (скорость, ускорение, длительности
  кликов, паузы, прямолинейность) с нормализацией по разрешению.
- Тесты (`pytest`), линт (`ruff`), типы (`mypy`), CI (GitHub Actions),
  упаковка (`pyproject.toml`).

### Удалено
- Легаси-модули `common.py` и `utils/*` (заменены пакетом).
- Хранение данных в `C:\MouseLog` — теперь `%LOCALAPPDATA%\MouseLogger`.

## [0.1.0] — 2018-08-04

Первоначальная версия: поллинговый логгер мыши с записью в TSV и автозапуском
через `.bat`.
