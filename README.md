# MouseLogger

Модуль сбора данных для исследовательского проекта **«Аутентификация пользователя по движению мыши»**.

Утилита фиксирует динамику работы с мышью (траектории движения, нажатия и
отпускания кнопок, временны́е метки) и складывает её в локальные лог-файлы.
Собранные данные используются как обучающая выборка для построения биометрического
профиля пользователя по поведенческому почерку.

> ⚠️ **Сбор данных ведётся только с явного согласия пользователя.**
> Утилита предназначена исключительно для исследовательского сбора данных на
> собственных или подконтрольных машинах при информированном согласии участника.
> Не используйте её для скрытого наблюдения за третьими лицами.

## Что записывается

В каждой строке лога — одно событие в формате TSV:

```
<action>\t<x>\t<y>\t<timestamp_ms>
```

| `action` | Событие                              |
|----------|--------------------------------------|
| `0`      | Маркер начала сессии                 |
| `M`      | Перемещение курсора                  |
| `L_D`    | Нажатие левой кнопки (Left Down)     |
| `L_U`    | Отпускание левой кнопки (Left Up)    |
| `R_D`    | Нажатие правой кнопки (Right Down)   |
| `R_U`    | Отпускание правой кнопки (Right Up)  |

`x`, `y` — координаты курсора в пикселях; `timestamp_ms` — Unix-время события
в миллисекундах. Подряд идущие одинаковые события (одно действие в одной точке)
не дублируются.

Состояние мыши опрашивается каждые 20 мс (`POLL_INTERVAL` в `utils/mouse_logger.py`).

## Использование

Утилита работает под Windows (используются WinAPI-вызовы `user32`).

```bat
MouseLogger.exe start        :: запустить логирование (без установки в автозапуск)
MouseLogger.exe install      :: добавить в автозапуск и сразу начать логирование
MouseLogger.exe uninstall    :: убрать из автозапуска, упаковать логи в архив, остановить процесс
```

Запуск без аргумента выводит подсказку.

### Где логи

Все логи собираются в каталоге `C:\MouseLog\`.
Имя файла — `<имя_пользователя>-<дата>.txt`.

При `uninstall` все логи каталога упаковываются в один архив `C:\MouseLog\MouseLog.zip`.

## Запуск из исходников

Нужен Python 3 (сторонние зависимости не требуются — только стандартная
библиотека и WinAPI через `ctypes`).

```bat
python main.py start
```

## Сборка .exe

```bat
pyinstaller --onefile --windowed --name MouseLogger --hidden-import=win32timezone main.py
```

## Структура проекта

```

utils/install.py            добавление/удаление из автозапуска Windows
utils/archived.py           упаковка логов в zip
```
