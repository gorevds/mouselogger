# MouseLogger

Модуль сбора данных для исследовательского проекта
**«Аутентификация пользователя по движению мыши»**.

Утилита фиксирует динамику работы с мышью (траектории, нажатия кнопок, прокрутку,
паузы, временны́е метки) и складывает её в локальные лог-файлы. Собранные данные —
обучающая выборка для построения биометрического профиля пользователя по
поведенческому почерку.

> ⚠️ **Сбор данных ведётся только с явного согласия участника.**
> Утилита предназначена для исследовательского сбора на собственных или
> подконтрольных машинах при информированном согласии. Команды `start`/`install`
> не запустятся без зафиксированного согласия. Не используйте утилиту для
> скрытого наблюдения за третьими лицами.

## Установка

Сторонних зависимостей для работы нет — только стандартная библиотека Python 3.10+
и WinAPI через `ctypes` (на Windows).

```bash
pip install .
```

После установки доступна команда `mouselogger`. Без установки можно запускать
через `python -m mouselogger`.

## Использование

```bash
mouselogger start --consent     # зафиксировать согласие и начать сбор
mouselogger start               # начать сбор (согласие уже дано ранее)
mouselogger install --consent   # прописать автозапуск Windows и начать сбор
mouselogger uninstall           # снять автозапуск, остановить сбор, заархивировать логи
mouselogger status              # состояние сбора и объём данных
mouselogger purge               # удалить все собранные данные (право быть забытым)
```

Остановить сбор — `Ctrl+C` (корректное завершение со сбросом буферов).

### Бэкенды захвата

`start`/`install` принимают `--backend`:

* `hook` (по умолчанию) — низкоуровневый системный хук `WH_MOUSE_LL`: событийно,
  без джиттера и пропусков, фиксирует прокрутку. Рекомендуется.
* `poll` — поллинг с фиксированной частотой (движение и кнопки, без прокрутки).

### Конфигурация (переменные окружения)

| Переменная | Назначение | По умолчанию |
|------------|------------|--------------|
| `MOUSELOGGER_DIR` | каталог данных | `%LOCALAPPDATA%\MouseLogger` |
| `MOUSELOGGER_PARTICIPANT` | идентификатор участника | генерируется и сохраняется |
| `MOUSELOGGER_SAMPLE_HZ` | частота опроса (1–1000) | `50` |
| `MOUSELOGGER_SCROLL` | фиксировать прокрутку | `1` |
| `MOUSELOGGER_CONSENT` | согласие на сбор | `0` |

Логи лежат в `<каталог данных>/logs`, архивы — в `<каталог данных>/archive`.
Идентификатор участника — псевдоним (не системный логин), чтобы данные не
содержали PII.

## Формат данных

Логи — JSON Lines (`.jsonl`), первая строка — метаданные сессии, остальные —
события. Полное описание схемы: [`docs/DATA_FORMAT.md`](docs/DATA_FORMAT.md).

## Экспорт признаков

Сборка сырых логов в таблицу признаков (CSV) для обучения:

```bash
python -m mouselogger.export <каталог-или-файлы>.jsonl -o features.csv
```

Координаты нормируются по разрешению экрана из метаданных; считаются скорость,
ускорение, длительности кликов, статистика пауз и прямолинейность. Метка строки —
`participant`.
